## Algorithm comparison

For every saved normal Track Lay position through revision 158, compatible tiles and all six rotations were tried directly against the engine's construction validator, without the discovery routine's reachable-hex prefilter. Results were compared by tile, hex and actual path geometry, so equivalent rotations of a straight tile count once.

- 18 track turns across phases 2 and 3.
- 13,206 candidate placement attempts.
- 133 distinct engine-accepted choices across those positions.
- Zero choices missing from server discovery; zero advertised choices rejected by the engine.

This verifies discovery against the engine for these positions. It is not an independent proof of every game rule or every possible later-phase board.

## UI defects fixed

1. The inline construction picker truncated its list to the first six legal options. It now renders every server-approved option. KO's seventh J3 option (#7 at rotation 5) was selected and committed through the browser after this fix.
2. “Rotate 60°” actually advanced through a list that could change both tile type and orientation. The label now says “Next legal option.”
3. Clicking a blocked hex gave a generic prompt to select some other highlighted hex. The construction panel and location inspector now explain the applicable restriction: normal lay already used, wrong step/player, no connection to the active railway's stations, phase, terrain funds, private-company block, exhausted supply, or permanent board location. These messages explain existing permissions; they do not grant actions or replace server validation.

The investigation changed no engine rules, live game snapshots, balances, or tile supplies.
